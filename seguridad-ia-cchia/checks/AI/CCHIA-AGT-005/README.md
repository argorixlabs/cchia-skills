# CCHIA-AGT-005 — Aprobación de acciones agénticas

Aplica a agentes/MCP con entradas externas o tools. Un system prompt no cuenta como autorización. Para obtener
E4, complementar la evidencia documental con pruebas de bypass, timeout, error, replay y mutación que demuestren
que las acciones rechazadas nunca alcanzaron el destino.
